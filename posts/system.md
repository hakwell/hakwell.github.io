# Building a Knowledge System

A good knowledge system helps me capture useful information without making organization harder than the learning itself.

## Keep it simple

I prefer a clear structure over a complicated one. A few repeatable habits are more valuable than a perfect archive.

## Capture context

Each note should answer:

- what question was I trying to solve?
- why does this matter?
- what source or example helped?
- what should I revisit later?

## Make notes easy to scan

Clear titles, headings, and links make notes easier to recover. I keep each note focused on a single topic when possible.

## Review and improve

Notes get better when I revisit them. I correct outdated points, merge duplicates, and update sections that grew stale.

Markdown is a good fit because it is simple, portable, and easy to import into tools like Notion.
